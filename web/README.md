# Budget Master — Web app & site

**All web app and site code lives in this folder.**

- Do **not** put web/site UI, routes, or front-end logic in the repo root or in `src/` (that’s the extension).
- Keep the extension in `../src/` and root `package.json` unchanged.
- This folder is self-contained: its own `package.json`, dependencies, and build.

## Setup

```bash
cd web
npm install
```

## Dev

```bash
npm run dev
```

## Build

```bash
npm run build
```

Preview production build: `npm run preview`.
