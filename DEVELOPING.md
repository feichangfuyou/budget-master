# Developing Budget Master

## Using the extension (no extra steps)

The extension is **installed in Cursor**. Open Cursor and use the **Budget Master** sidebar (graph icon). You don’t need to run “Run Extension” or start anything.

## Updating the extension while you code

1. **Start dev mode once** (choose one):
   - **Cmd+Shift+P** → “Tasks: Run Task” → **dev**, or  
   - In a terminal: `npm run dev`

2. **Edit** `src/*.ts` and save. The project will compile, package, and reinstall the extension automatically.

3. **Reload Cursor** to load the new build: **Cmd+Shift+P** → “Developer: Reload Window”.

After that, the extension in your sidebar is running your latest code.
